1. **M5a 产品打磨**:OSC 133 UI 消费(jump + exit code 状态点)、OSC 8 hover
   tooltip、undercurl(SGR 4:3)、拖选接续滚轮扩展选区、bold-italic 面、
   OSC 4 索引 16-255(立方/灰阶)、系统按钮/标签溢出打磨、QT 无修饰键编码、
   I2 半纹素渗色处方、每标签独立字体/字号

   (永不上传)、PTY 退出态 + 重开按钮、IME 组合窗口跟随光标(Imm32)、
   per-monitor DPI(退役写死 96)
3. **M5c 发布收尾**:最小 UIA 无障碍、自建基准器 + CI 防退化 + 对照结果页、
   winget 清单首提、README/文档完备、版本 1.0 + tag 发版

**非目标(1.0 砍单)**:标签 tear-off(两轮观望,无人要)、defterm 二级 COM
(一级 RRVA 够 1.0,金丝雀文化守边界)、官网/社区基建(README + 仓库内
文档足够;域名是所有者个人决策)、kitty graphics(ConPTY 边界,M4c 定论)、
连字 TextLayout 引擎(留观 1.1,Cascadia 系才受益)、代码签名(证书成本,
接受 SmartScreen 提示,README 写明)、完整状态行(TUI 会覆盖,只做状态点)

## 3. M5a 产品打磨

### OSC 133 UI(D37)

- 数据层升级:`pending_marks` 从"取走即丢"升级为 Surface 持久行属性表
  (`marks: Vec<RowMark>`,按行合并去重;行号随滚动漂移的问题在消费时
  换算——jump 目标 = 该行的 display_offset 对准,不做反向追踪)
- D 标记 exit code:sidecar 解析 `133;D;err=<n>`(官方是 err 键;M4b 全丢)
- jump:Ctrl+Shift+↑/↓ 在最近的 A(prompt start)行间跳;键位进 KEYMAP
- 状态点:app 标题栏右侧 6px 圆点,D 到达即绿(exit 0)/红(非 0),
  持续到下一个 B(命令开始)

### 其余 M5a 任务

- **OSC 8 hover**:TrackMouseEvent 悬停 300ms,自绘 URL 气泡(顶层无边框
  窗,复用 strip 管线);离开即消。Ctrl+Click 语义不变(M4b 已交付)
- **undercurl(SGR 4:3)**:alacritty 上游不认 4:3(降级普通下划线),
  需旁路状态跟踪——**探针先行**:先确认 vte 对 `4:3` 的 subparam 传递
  形态,再定 sidecar 扩展或 Handler 拦截;波浪渲染 = shader 变体
  (直线 quad → 正弦 UV 裁剪,ink_mask 同源)
- **拖选接续滚轮**:selection 激活时滚轮改 display_offset 并把选区端点
  扩展到视口边缘行(上游 Selection 接受任意 buffer 点,纯接线)
- **bold-italic 面**:dwrite 字体链样式匹配三态(现 italic 在 bold 下丢);
  回归锁:三态产出不同字形位图
- **OSC 4 索引 16-255**:`palette::query` 补 256 色标准公式(16-231 立方
  6³,232-255 灰阶 8+10n)——应答与渲染(色段)同源收敛
- **系统按钮/标签溢出打磨**、**QT 无修饰键编码**、**I2 渗色处方**
  (atlas insert 右/下 +1px 零填充)、**每标签独立字体/字号**(tab 持
  Settings 覆盖子集;若配置模型溢出则只落字号,字体 1.1——任务内自裁量)

## 4. M5b 健壮性(D35)

- **device lost**:`request_adapter_options` 加 uncaptured error handler +
  `set_device_lost_handler` → 置标志 + 主循环重建 GpuContext/管线/纹理,
  force_full 一帧;WARP 兜底保留
- **panic hook + minidump**:`MiniDumpWriteDump`(windows-rs)写
  `%LOCALAPPDATA%\mica\crash\<ts>.dmp`,首屏提示文件路径;**永不上传**
  (Ghostty 哲学);渲染线程 panic 不杀 pty 数据(读线程隔离已具备)
- **PTY 退出态**:child exit → surface 冻结最后一帧 + strip 提示
  "进程已退出(<code>)";Ctrl+Shift+R 或点击重开(同 profile 新 pty);
  关闭语义不变(末标签退出仍要显式关)
- **IME**:Imm32 全套——`ImmSetCompositionWindow` 候选框跟随光标格、
  `GCS_RESULTSTR` 经 WM_CHAR 路径上屏、组合中文本以虚线下划线预显;
  冒烟矩阵:微软拼音 + 搜狗(主流两款)
- **per-monitor DPI**:WM_DPICHANGED → FontMetrics 按 DPI 重算 → 网格
  换算 + ConPTY resize + 图集重建;写死 96 退役(度量数学层不动的,
  只在入口乘 scale)

## 5. M5c 发布(D33/D34/D36)

- **UIA 探针先行**:windows-rs 的 UIAutomation COM 绑定可用性核实 →
  最小:控件名/角色/终端区域矩形;Narrator 冒烟过即收
- **基准器**:吞吐(10MB 混合样本计时 feed+damage,已有 sidecar 基准
  变体)+ 输入延迟(事件循环节拍估算 + 人工复核);CI job `perf`,
  基线存仓库,回归 >5% 红
- **结果页**:`docs/benchmarks-1.0.md`,自测数据 + WT/Alacritty/WezTerm
  人工对照(hyperfine 外部计时),第三方公开数据引用注明来源
- **winget**:打 v1.0.0 tag → release(附 CI 产 MSI)→ winget-pkgs
  manifest-only PR(InstallerUrl 指 release asset,多 arch 单 x64 起步)
- **README/文档**:安装(winget/MSI/源码)、键位表、配置语法、SmartScreen
  说明、ConPTY 边界三条(2026/OSC52/APC)如实写
- **版本**:workspace version 1.0.0,发版 PR(main)后 tag

## 6. 冒烟清单(M5 收官)

1. 中文输入法:候选框跟随光标、组合预显、上屏正确(两款输入法)
2. Narrator:能读出窗口名/标签数,终端区域可定位
3. 断 GPU(设备管理器禁用显卡):自动重建不崩,WARP 兜底可继续用
4. 人工触发 panic:产生 dmp 文件,提示路径
5. 关闭 shell(exit):退出态 + 重开按钮,退出码正确
6. prompt 间 jump ↑/↓;exit code 状态点绿/红
7. OSC 8 悬停显 URL 气泡
8. 多屏拖动(不同 DPI):字号即时正确
9. winget install(清单沙箱验证)
10. CI perf job 绿 + 结果页数字与 CI 一致
11. undercurl 显示(vim diagnostic 场景)
12. 拖选 + 滚轮扩展选区复制大段
