## 任务

### T1 marks 持久化 + exit code 解析(core,TDD)

- `ShellMark::CommandEnd` → `CommandEnd { exit: Option<i32> }`(lenient:
  `err=0` / 裸数字两种形态都收;FinalTerm/各家实现不一致)
- Surface:`pending_marks`(取走即丢)升级为 `marks: Vec<RowMark>`
  + 每 mark 记录 `epoch = history_size()`;新增 `shell_marks()` 返回
  换算后的视口行表:`current = line - (hist_now - epoch)`(内容上滚、
  行号减小、history 同步增长的恒等式);take_shell_marks 退役,
  app 的排空点改调 shell_marks(消费式 API 保无积压语义则改为幂等读)
- 测试:滚动后行号换算正确、D 带参/无参、err= 与裸数字

### T2 jump 键位(app)

- KEYMAP:Ctrl+Shift+↑/↓ = JumpPrevPrompt/JumpNextPrompt
- 对准公式:目标行 L 置于视口第 2 行 → `display_offset = (2 - L).max(0)`
  的负值方向……即 `scroll_display(Scroll::Delta((2 - L).max(0) 视口差))`;
  活动屏内(L ≥ 0 且 < screen_lines)不滚,只闪提示
- 不动光标;marks 表空时 no-op
