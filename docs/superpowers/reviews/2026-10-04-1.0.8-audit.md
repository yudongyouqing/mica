# Mica 1.0.8 大审查(五维度)

- 日期:2026-10-04(1.0.0→1.0.8 九连发次日)

- 方法:五维度扫描(panic/测试盲区/依赖/资源累积/帧循环)+ 三危险模式
  (A 文档轻描淡写实为雷、B 会挂死的 drop/join 链、C 文档声明 vs 代码漂移)

## P1(下版必修)

1. **spawn shell/forwarder 用 expect(app.rs:1117/531/1237)**:内存紧张时
  (实测:游戏吃 5GB 后)新建标签=整个 app 闪退。修法:降级成 MessageBox
  警告 + 不建标签,进程活着。(今日审查第一发现)

## P2(票箱)

2. **锁 poisoned expect(8 处)**:读线程持锁 panic 会级联主线程闪退;
  概率极低(锁区纯 IO),改 `unwrap_or_else(|e| e.into_inner())` 与
  surface.rs 的 lock() 同款即可,顺手清。
3. **SEH crash filter 无测试**:native 崩溃档案是基建(1.0.8 新增),
  应加 `--crash-native-test`(触发 AV 断言 dmp 落盘)。
4. **kill_child 无测试**:退出杀子链是 1.0.4/1.0.5 的核心修复,
  应有集成测试(spawn mica→强杀→验子进程死)。
5. **CLAUDE.md 边界清单 48 条已过二轮审查,但新增修复(defterm 撤除/
   UIA 撤线/泄漏哲学)未全部反映**——每次发版后同步边界清单进流程。
