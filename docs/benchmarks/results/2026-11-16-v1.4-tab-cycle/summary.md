# v1.4 真实标签生命周期资源曲线(200 轮)

2026-11-15 夜在空闲桌面用现代 tab-cycle 驱动(2026-11-11 版,隔离身份 +
PID+FILETIME 核验 + 低内存安全帽)对 v1.4 候选跑满 200 轮,全部通过:
每轮关闭后回到 2 条 Running / 0 条 Closing 注册记录、4 个自有子进程,
无累计标签、无 CLI 失败、无兜底清理;主窗 WM_CLOSE 正常退出。

## 版本与环境

- 源码 `fc05aee`(= v1.4.0 发布内容),release EXE SHA-256
  `d91ebad3e1be04cf43532a578307580c081a49574a7fb27b6b41efdedc1b5185`。
- Windows 11 10.0.26300,16 逻辑 CPU,16.9 GiB 物理内存,
  NVIDIA RTX 4060 Laptop(驱动 32.0.16.1656),DX12,150% DPI。
- 驱动自带隔离(独立 APPDATA/LOCALAPPDATA/USERNAME),关闭光标闪烁与
  strip 动画,Delete 全修饰组合绑定 close_tab;完整 config 存于运行目录
  `environment.json`(临时,不入库)。
- 对照基线:同机 `docs/benchmarks/results/2026-11-11-post-hardening/`
  (源码 19c9afd,200 轮,方法学一致)。

## 计数器口径与未取得项

- 主进程 Private Bytes / Working Set / 句柄 / 线程:每轮关闭后采样
  (psutil);子进程仅按 PID+创建时间核验的**数量**计(4 恒定),
  子进程内存未单独采样——记**未取得**,不以 0 充数。
- GPU 专用/共享显存计数器:驱动未采样——**未取得**(如需,后续用
  DXGI 显存枚举补)。
- 样本 1246 个(启动静置 15s + 200 轮 + 结束静置 30s),可见窗口样本
  1245;最低系统可用内存 3.49 GiB(安全帽 2 GiB 未触发)。

## 与 2026-11-11 基线对照(同机同学法)

| 指标 | 基线(19c9afd) | 本轮(v1.4) | 判读 |

varying + clamp(不增实例 ABI),实测斜率印证无累积开销。
